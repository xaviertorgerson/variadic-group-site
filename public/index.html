How the machine works

  1. A person writes the spec: what to build, and why.
  2. Agents break it into tasks, write the code and review every change.
  3. A change merges only when every automated check passes.
  4. A person approves each release to production.

Underneath every product is the same company: one LLC, one bank, one way to take payments and sales tax, the same legal pages, support inbox and servers. A new product inherits all of it on day one. Every decision is written down in the code repository with its reason, so the next product starts where the last one left off.
